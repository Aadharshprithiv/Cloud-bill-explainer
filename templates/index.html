Where do I find my AWS bill as a CSV? ▾
  1. Sign in to the AWS console and open Billing and Cost Management.
  2. Go to Data Exports (older accounts: Cost and Usage Reports) and create an export if you don't have one. Choose CSV format.
  3. AWS saves the report to an S3 bucket within about a day. Download the file for the month you want.
  4. If the file ends in .gz or .zip, unzip it first, then upload the .csv.
